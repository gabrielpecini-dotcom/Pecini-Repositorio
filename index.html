Código para VS Code & GitHub

Guia de instalação por Gabriel Gonçalves Pecini

Este projeto foi desenvolvido como um arquivo único HTML completo e autosuficiente, pronto para ser executado no VS Code e hospedado no GitHub Pages.

Passo 1: Rodar no VS Code
  1. Crie uma pasta no seu computador com o nome ache-pro-maringa.
  2. Abra essa pasta no VS Code.
  3. Crie um arquivo chamado index.html e cole todo este código fonte.
  4. Instale a extensão Live Server no VS Code e clique em "Go Live" para testar no seu navegador.
Passo 2: Publicar no GitHub Pages
  1. Crie um repositório no GitHub com o nome ache-pro-maringa.
  2. Suba o arquivo index.html para o repositório principal (main ou master).
  3. Vá em Settings > Pages do seu repositório no GitHub.
  4. Em Branch, selecione main / root e clique em Save.
  5. O seu site estará no ar gratuitamente em minutos!
